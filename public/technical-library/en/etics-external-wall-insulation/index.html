ETICS External Wall Insulation System

System Overview

This ETICS build-up combines graphite EPS insulation, reinforced base coats, primer and a textured finishing render. Correct detailing and project-specific verification support thermal performance and a durable façade suited to Mallorca’s climate. A complete system approach is essential: adhesive, insulation, fixings, reinforcement layers, profiles, primer and finishing render must be selected as mutually compatible components.

Eight-Layer ETICS Build-Up

  1. 1

    Structural wall substrate

    Assessed and prepared masonry or mineral wall supporting the complete system.

  2. 2

    Adhesive mortar

    Compatible mineral adhesive securely bonding insulation to the substrate.

  3. 3

    Graphite EPS façade insulation

    High-performance external insulation reducing heat transfer in a compact build-up.

  4. 4

    First reinforcement / base-coat layer

    Compatible reinforcement mortar forming the base for embedded mesh.

  5. 5

    Alkali-resistant reinforcement mesh

    Glass-fibre mesh fully embedded with correct overlaps and profile connections.

  6. 6

    Second levelling / finishing base coat

    Levelling coat covering the mesh and creating an even finishing substrate.

  7. 7

    Primer

    Compatible façade primer matched to the render and substrate conditions.

  8. 8

    Decorative finishing render (exterior crepi)

    Warm sand textured exterior crepi forming the visible weather-protective façade finish.

Key Technical Principles

Substrate preparation

The structural wall must be stable, clean, sufficiently even and suitable for adhesive application.

Thermal continuity

Continuous external insulation reduces winter heat loss, limits summer heat gain and helps maintain more stable internal surface temperatures.

Reinforcement and overlaps

The reinforcement mesh must be fully embedded with correct overlaps and continuous connections to all PVC profiles.

Complete system compatibility

A complete Baumit ETICS solution uses mutually compatible adhesive, insulation, fixings, reinforcement layers, PVC profiles, primer and finishing render, supported by the applicable system documentation.

Examples of Components Used in the System

Selected system components are shown below. Profiles are PVC system profiles with integrated reinforcement mesh; aluminium profiles are not used. Recessed installation of the fixing with an insulation cap helps reduce visible fixing marks and local surface-temperature differences.

Important / Compliance

Use complete, mutually compatible Baumit system components supported by the applicable European Technical Assessment, CE documentation and manufacturer system specifications. Final selection and installation must comply with the Spanish Building Code and project-specific requirements.

Key Benefits

Lower heating and cooling demand

Continuous external insulation reduces winter heat loss and limits summer heat gain through the façade.

Reduced thermal bridges

A continuous insulation envelope limits local weak points around the structural wall.

Improved indoor comfort

More stable internal surface temperatures support a more comfortable indoor climate.

Protected building fabric

The external system helps protect the structural wall from strong temperature fluctuations.

Durable finish when correctly detailed

Compatible components, reinforced layers and correct connections support a long-lasting façade system.
