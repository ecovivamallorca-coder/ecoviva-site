Status: ACTIVE BASELINE

## Core principle

Search behaviour -> useful answer -> technical authority -> EcoViva guidance -> Intake.

EcoViva should enter the owner's decision process before contractor comparison whenever possible: at the problem, research, cost, buying or renovation-from-abroad stage.

SEO must reinforce the core EcoViva positioning: EcoViva does not simply sell labour; it provides a controlled renovation experience with independent guidance, technical understanding, coordination, quality assurance and one point of contact.

## Moisture rule

Never treat moisture as one generic problem. At minimum distinguish:

- condensation
- capillary / rising damp
- external water infiltration

The cause must be identified before linking to a Technical Library solution. ETICS, for example, may be relevant to cold-surface condensation and thermal bridging but must not be positioned as a universal damp solution.

## Header / navigation decision

Add one new navigation area for the evergreen search-content layer.

Recommended labels:

- EN: Guides
- ES: Guias
- DE: Ratgeber

Do not use Articles or Blog as the primary label. These pages are evergreen decision-support pages, not news posts. Guides fits EcoViva's premium advisory positioning and clearly separates this layer from the Technical Library.

## Internal-link model

- Problem page -> diagnosis -> relevant Technical Library system -> Intake.
- Cost page -> cost drivers / scope -> Intake.
- Commercial renovation page -> EcoViva process -> Technical Library -> Intake.
- Buying / pre-purchase page -> risk and scope guidance -> Intake.
- Technical Library -> remain technically authoritative; CTA to start renovation / Intake.

## Search Console operating method

Once impressions accumulate:

- High impressions + average position 8-20 = high optimisation opportunity.
- High commercial relevance + low impressions = review indexing, search fit and content depth.
- Strong clicks but weak enquiries = conversion or intent mismatch.
- Pages already ranking top 5 = defend and deepen rather than constantly rewrite.

## Content quality rules

- Mallorca-specific, technically credible and genuinely useful.
- No mass-produced thin pages for keyword variations.
- One strong page may target a coherent cluster of synonyms and related questions.
- Native EN / ES / DE phrasing, not literal translation.
- No unsupported technical, legal, cost or performance claims.
- Every page must have a defined conversion destination before publication.
- Technical Library remains the technical authority layer; Guides captures real search questions and problems.
