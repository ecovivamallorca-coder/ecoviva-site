# EcoViva website KISS and conversion plan

Updated: 11 October 2026

## Objective

Make every public EcoViva page immediately understandable to visitors and search engines while preserving current URLs, canonicals, hreflang links and sitemap structure.

## Rules for every page

1. One primary search intent and one primary service.
2. State the service, location and target customer above the fold.
3. Use one primary CTA and no more than two secondary actions.
4. Keep commercial pages focused on customer problems, scope, process and next step.
5. Keep detailed system explanations in the Technical Library.
6. Link every Technical Library page to one relevant commercial service page.
7. Link every Guide from the problem to the relevant commercial solution.
8. Preserve existing URLs. Use redirects only when a URL change is unavoidable.
9. Maintain EN, ES and DE parity.
10. Deploy one reviewed page cluster at a time. Do not request manual indexing after normal copy or internal-link updates.

## Indexing policy

Normal text, CTA and internal-link changes are discovered through regular crawling and the existing sitemap. Do not manually submit pages after each update.

Request indexing only when:

- a genuinely new priority page is published;
- a page remains unindexed;
- a canonical, redirect or robots issue is corrected;
- Search Console reports a specific indexing problem.

## Completion checklist per cluster

- Clear service and Mallorca in the opening section.
- One primary CTA.
- No competing page targets the same primary intent.
- Correct links from homepage, Guides and Technical Library.
- EN, ES and DE checked.
- Mobile layout checked.
- No URL, canonical, hreflang or sitemap regression.
- Production deployment successful.
